## Known Limitations

- MLX requires Apple Silicon and macOS 14+. Not available on Intel Macs.
- Character throughput is not token throughput.
- MLX benchmark results are hardware-specific.
- Live Codexify integration has not been completed.
- Non-streaming MLX cancellation is cooperative/best-effort.
- `mlx-lm` is optional; default install does not pull it.
