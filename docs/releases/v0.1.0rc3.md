# Whoosh'd v0.1.0rc3

**Local-first inference gateway for Apple Silicon and self-hosted AI workflows.**

---

## What It Is

Whoosh'd exposes OpenAI-compatible chat and model surfaces while coordinating
local runtimes like MLX and llama.cpp — with explicit health, readiness,
runtime visibility, and safety boundaries.  Built to be useful standalone,
but especially sharp as the local runtime layer beneath Codexify.

---

## What's New Since v0.1.0rc2

### Runtime Readiness

- **Smoke scripts** — `scripts/smoke_stub.sh`, `scripts/smoke_threadwake.sh`,
  `scripts/smoke_openai_compat.sh` verify the server surfaces live against a
  running stub instance. 12/12 checks passing.
- **Example env files** — copy-pasteable configs for stub, Codexify, MLX, and
  llama.cpp in `examples/`
- **Runtime surface map** — which endpoint answers which question
- **Local sanity checklist** — 8 curl commands that work without models or GPU
- **Troubleshooting guide** — 7 common symptoms with checks

### ThreadWake Metadata Milestone

ThreadWake is Whoosh'd's prompt-prefix reuse optimization.  This release
includes the full metadata pipeline:

- Observe-mode prompt analysis
- Candidate telemetry, scoring, and policy engine
- Snapshot manifest and artifact registry
- Metadata-only periodic analysis loop
- Read-only visibility (`/health/threadwake`, `/runtime/threadwake/analysis`)
- Operator runbook and documentation index

**KV reuse is not enabled.  Durable snapshots are deferred.  No backend is
production-ready for KV materialization.**

### Internals

- 614 tests passing

- Backend materialization interface, artifact registry, snapshot policy

## What Is Intentionally Not Included

- KV reuse across requests
- Durable KV snapshots to disk
- KV snapshot restore
- Production backend materialization
- ThreadWake enabled by default (it's off)

## Quick Start

```bash
git clone https://github.com/Resonant-Jones/whooshd.git
cd whooshd
pip install -e ".[dev]"

# Start stub server (no models needed)
WHOOSHD_ADAPTER=stub uvicorn whooshd.app:app --port 8000

# Run smoke checks
sh scripts/smoke_stub.sh
sh scripts/smoke_threadwake.sh
sh scripts/smoke_openai_compat.sh
```
